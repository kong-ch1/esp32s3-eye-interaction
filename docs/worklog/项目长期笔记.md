# AI交互课 项目长期笔记

## 课程框架：单元1 最小交互闭环与设备反馈（第1—3周）
- 目标：单源采集→VPS→Web 系统；Web 发"重新采集"请求并追踪设备执行；实体按键+本地/远端反馈。
- 评价证据：板端/服务端/Web 工程、VPS部署结果、真实观测与页面对应、请求—回执—新观测记录、实体操作与个人修改。
- 难点（评分重点）：数据值/来源/采集时间对应；刷新存储记录 vs 触发新采集的区别；服务器受理/设备接收/完成/超时的证据链。
- 范围控制：第1周 1个真实传感源+1种已验证网络；第2周有限采集任务，不重写底层协议；实体求助只发教学测试端。

## 硬件（ESP32-S3-EYE）
- IMU 实装 **QMA6100P**（CHIP_ID=0x90），原理图标称 QMA7981（已 EOL，pin-to-pin 兼容）。
- 摄像头 OV2640（自带 JPEG 硬编码，MJPEG 流端口 81）。
- WiFi SSID `431` / pass `88888888`；服务器地址写死 `10.1.41.18:8000`（局域网，待改可配置）。

## 进度对照
- 第1周 ✅：IMU(QMA6100P) + 摄像头 + Web 展示；服务器 `server.py` + 中转 `camera_relay.py`（自愈已加）。
- 第2周 ⏳：Web→服务器→板子 的"重新采集"指令通道 + 回执状态机（issued/received/done/timeout，带 request_id 关联）。

## 传感器静态噪声基线（2026-09-14 实测，600 条 / 13.5 分钟，板子静止）
- 工具：`tools/analyze_noise.py [样本数] [设备名]`，输出各轴均值/标准差/峰峰值 + 温度相关系数。
- 实测：**ax sd 15.2mg、ay 7.2mg、az 6.3mg、|a| sd 6.3mg**；峰峰值约 60mg（0.06g）。
- **|a| 均值 1.0030 g**（静止应为 1.0g，偏差 0.3%）→ 传感器与 CAL_* 标定均正常。判读：|a| 长期均值≈1.0 就说明没坏。
- 芯片温度均值 52.7°C，但**13 分钟内波动 13°C**（44.3~57.3），TSENS 读数噪声不小，别当精密温度计。
- **温度与加速度相关系数 ≈ 0.02（-0.02~+0.05）→ 无关**。即短时抖动**不是**温度漂移，主因是 MEMS 本底噪声 + 环境微振动 + 供电纹波。
- 结论（答疑用）：静止 ≠ 读数恒定。网页 3 位小数看到跳动是正常物理噪声，不是 bug。想让显示"稳"可降显示位数或加滑动平均（会牺牲响应速度）。
