## 关于原始记录

`raw/session-2026-09-08_2026-09-18.jsonl` 是工具的会话日志原文，每行一条记录，包含：

- `message`（`role: user` / `assistant`）—— 对话正文
- `function_call` —— AI 调用的工具及其参数（含文件读写内容）
- `function_call_result` —— 工具返回结果
- `reasoning` —— AI 的推理过程
- `file-history-snapshot` —— 文件变更快照

它是**可机读的完整审计轨迹**：任何一条代码改动都能在其中找到对应的工具调用与时间戳。
逐日纪要（上面的 `YYYY-MM-DD.md`）是从它整理出的可读版本，为避免文档过大，
AI 单条回复超过约 1500 字的部分做了省略标注，完整内容请查原始记录。

## 说明

对话记录中包含开发环境的路径、内网 IP（`10.1.41.x`）与 WiFi 名称等信息。
